AgentGate

Postgres pull requests for AI agents. A proposal is reviewed, then merged. The business row changes only when a receipt records the commit.

This page is an illustration. The buttons step through a fixed story for invoice 482. They do not call an API. Run the live demo locally with docker compose -f compose.demo.yml --profile demo up --build, then open http://127.0.0.1:8090. After this repository is published, the rendered page is https://<agentgate-org>.github.io/agentgate/.
